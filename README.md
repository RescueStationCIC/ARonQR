# ARonQR
An AR project for a SPWA which projects a 3D scene on top of a QR code. The QR code contains the github pages URL for the SPWA, the URL to the model and the the parameters for the scene.

Any model needs download of attribution: 
e.g: https://sketchfab.com/3d-models/earth-41fc80d85dfd480281f21b74b2de2faa
